# Meus sites favoritos: Rogerio Camargo

Página web desenvolvida em **HTML5 e CSS3** para guardar meus sites favoritos, com visual moderno e elegante (tema escuro com detalhes dourados).

## 📌 Sobre o projeto

A página reúne 5 sites que eu uso no dia a dia. Para cada site, a página mostra:

- **Acima da imagem:** o nome do site (tag `<h1>`)
- **No meio:** uma imagem do site, que também funciona como link
- **Abaixo da imagem:** o link para o site (tag `<a>`)

| Site | Categoria | Link |

## 🛠️ Tecnologias utilizadas

- **HTML5**: estrutura da página (`<title>`, `<h1>`, `<img>`, `<a>`, `<ul>`, `<li>`)
- **CSS3**: estilo, cores, fontes, grade responsiva (`grid`) e animações ao passar o mouse
- **Google Fonts**: fontes Bodoni Moda (títulos) e Manrope (textos)

## 📁 Estrutura da pasta

```
rogerioCamargo_Ag12_DS_I/
├── rogerioCamargo_Ag12_DS_I.html   # página principal (código comentado)
├── README.md                       # este arquivo
├── captura-codigo.png              # print do código com comentários
└── captura-navegador.png           # print da página aberta no navegador
```

> As imagens dos sites estão embutidas no próprio código HTML (formato SVG), então a página funciona sem arquivos de imagem separados.

## ▶️ Como executar

1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/rogerioCamargo_Ag12_DS_I.git
   ```
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo `rogerioCamargo_Ag12_DS_I.html` para abrir no navegador.

## 📱 Responsividade

A página se adapta ao tamanho da tela:

- **Computador:** 3 sites por linha
- **Tablet:** 2 sites por linha
- **Celular:** 1 site por linha
